# ソートアプリ

このアプリケーションは、指定された数値をソートアルゴリズムを使用して並べ替えるためのウェブアプリです。

## 主な機能
- カンマ区切りで入力した数値を並べ替えます。
- クイックソート、ラディックスソートアルゴリズムを選択できます。
- ソート結果を表示します。

---

## 動作環境

このアプリケーションは、Docker を使用して簡単にセットアップできます。

---

## 起動方法

1. **Docker を起動する**
    ```
    docker compose up -d
    ```

2. **ウェブブラウザでアプリにアクセスする**
   - URL: `http://localhost:8000` (ポート番号は環境に応じて変更してください)

---

## 使用方法

1. **値の入力**
   - カンマ（`,`）で区切られた数値を入力します。例: `5,3,8,6,2`

2. **ソートの種類を選択**
   - ドロップダウンからクイックソートやラディックスソートを選択します。

3. **実行**
   - 「ソート開始」ボタンを押して、並べ替えを実行します。
   - 結果がリアルタイムで表示されます。
